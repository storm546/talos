The debug-only lite pose model is the MediaPipe Pose Landmarker float16 model, version 1,
from https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task.
It is used only by the explicit two-pass timing experiment. It is not bundled in release builds.
